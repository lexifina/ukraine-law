# Стаття 208
Пільги для працівників, які навчаються у закладах середньої, професійної, фахової передвищої освіти
Для працівників, які навчаються без відриву від виробництва у закладах середньої, професійної, фахової передвищої освіти, встановлюється скорочений робочий тиждень або скорочена тривалість щоденної роботи із збереженням заробітної плати у встановленому порядку; їм надаються також і інші пільги.
