# Стаття 64
Необхідність одержання дозволу виборного органу первинної профспілкової організації (профспілкового представника) підприємства, установи, організації для проведення надурочних робіт
Надурочні роботи можуть провадитися лише з дозволу виборного органу первинної профспілкової організації (профспілкового представника) підприємства, установи, організації.
