# Стаття 203
Негайне припинення дії запобіжних заходів
1. Ухвала про застосування запобіжного заходу припиняє свою дію після закінчення строку дії ухвали про обрання запобіжного заходу, ухвалення виправдувального вироку чи закриття кримінального провадження або винесення ухвали про скасування запобіжного заходу в порядку, передбаченому цим Кодексом.
